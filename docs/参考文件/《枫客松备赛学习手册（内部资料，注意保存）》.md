## 1 这场比赛在考什么（先想清楚，再学工具）

一句话：**用 AI 把栖霞山的一个真实问题，变成一个 48 小时内能演示给游客和评委看的答案。**

四个隐藏考点：

- 文旅落点：所有东西必须跟栖霞山、跟游客绑得上，做"通用 AI 作品"会失分。
- 现场感：Day1 安排了"上山采风 + 游客访谈"，谁把现场素材用进作品，谁就有真实感。
- 可演示性：观众体验投票意味着作品要"可围观、可体验、30 秒能看懂"。
- 讲述力：最后的展演只有几分钟，讲不清约等于没做。

新手总策略：**小而完整 > 大而残缺**。先保证"能跑、能讲、能被感受到"，再谈复杂度。

## 2 概念摘要：AI 新手 3 周必懂的概念（按优先级）

### 2.1 大语言模型（LLM）与日常协作

- 一句话：一个会聊天、会写作、会编程的"通才实习生"。
- 必须懂的词：提示词（prompt）、上下文（它一次能记住多少）、Token（长度/计费单位）、幻觉（自信地编造）、系统提示（给 AI 的长期人设）。
- 比赛用途：写讲解词、生成文案、写代码/公式、当策划顾问和你"对吵"。
- 掌握标准：知道它擅长什么、什么时候不能信；会用"追问 + 让它自查"把结果磨好。
- 练习：每天用它完成 1 件真实小事（写报名材料、整理资料、起队名）。

### 2.2 提示词工程（Prompt）

- 结构公式：**角色 + 任务 + 背景 + 约束 + 示例 + 输出格式**。
- 高频技巧：给 2 个样例（少样本）、让它先列提纲再写（分步）、让它先问你 3 个问题再动手、要求表格/JSON 等结构化输出、不满意就"指哪儿打哪儿"地改。
- 比赛用途：讲解词、活动文案、展演讲稿、给智能体写"人设"。
- 掌握标准：同一个任务，3 轮迭代能把质量从"能看"推到"能用"。
- 练习：同一段栖霞山介绍，写 3 版提示词（讲给小孩 / 讲给考据党 / 讲给短视频观众）。

### 2.3 多模态生成：图片与视频

- 概念：文生图、图生图（垫图）、文生视频、图生视频；风格控制、参考图、一致性（同一角色/场景不崩）、镜头语言。
- 工具（国内可用优先）：即梦（图 + 视频）、可灵（视频）、通义万相、剪映内置 AI 功能。
- 比赛用途：赛道一的"新影像"；两条赛道的宣传物料和界面配图。
- 掌握标准：能做出一组风格统一的图片 + 1 条 5 秒动态镜头；知道哪些素材因版权不能直接用。
- 练习：把"栖霞山红叶 + 古寺"做成 3 种风格概念图，挑一版继续做动态。

### 2.4 语音：声音叙事的技术底（赛道一重点）

- 概念：TTS 语音合成、声音克隆（须有授权，慎用真人声音）、ASR 转写、配乐与音效。
- 工具：剪映"朗读"、豆包/通义等语音能力、各类 TTS 平台（先用免费额度）。
- 比赛用途："一段声音叙事"可能就是作品的灵魂：让千佛岩"开口"、复原历史现场的声音（钟声、梵音、风声、叶响）。
- 掌握标准：把 200 字讲解一键变音频，并会叠加一层环境声。
- 练习：为"千佛岩"写 200 字讲解 → 转成音频 → 加环境声，做成 30 秒片段。

### 2.5 智能体与知识库（赛道二核心）

- 概念：智能体 = 大模型 + 人设/目标 + 知识库 + 工具 + 记忆；RAG（检索增强生成）= 回答前先查资料，减少胡编。
- 平台（低代码、新手友好）：扣子 Coze、Dify——都可上传知识库、做多轮问答、生成分享链接。
- 比赛用途："最懂栖霞"的 AI 导游：行前规划、在场讲解、游后纪念。
- 掌握标准：上传资料 → 做出能"问不倒"的问答机器人 → 分享链接给别人能玩。
- 练习（本周就能做）：把本手册 §3 的素材丢进知识库，做一个"栖霞山 20 问"机器人。

### 2.6 工作流、接口与评测

- 概念：工作流（多步骤自动化，如"收到问题 → 查资料 → 生成语音 → 返回"）、API（程序间调用、用 Key 计费）、评测（自建测试集看正确率）。
- 比赛用途：把 demo 串成一条顺滑的"体验流"；提前发现"答错/翻车"点。
- 掌握标准：设计一条 3 步以上的流程并跑通；为作品写 20 条测试问题，能说出错在哪。
- 练习：给 2.5 的机器人做 20 题自测，把答错的 5 题修好。

## 3 领域知识：栖霞山素材库 v0（重点！）

### 3.1 名号速记

栖霞山，又名**摄山**：位于南京东北郊、距城区约 22 公里；主峰凤翔峰 286 米；古称"**金陵第一明秀山**"，有"**一座栖霞山，半部金陵史**"之说；中国**四大赏枫胜地**之一；国家 4A 级景区 + 国家级森林公园；古迹遗址 80 余处。

### 3.2 关键时间线

| 时间 | 事件 |
| --- | --- |
| 南朝齐（约 484–489） | 明僧绍隐居摄山，舍宅"栖霞精舍"为寺；其子与智度禅师凿千佛岩，489 年"西方三圣"像完成 |
| 南朝梁 | 僧朗在此大弘"三论"之学，栖霞寺渐成三论宗祖庭 |
| 隋（601–602） | 隋文帝立舍利塔诏，以蒋州（今南京）栖霞寺为首 |
| 唐 | 与灵岩、玉泉、国清并称"四大丛林"；高宗李治撰《明征君碑》，高正臣书，碑阴"栖霞"二字相传为御笔 |
| 南唐 | 重修栖霞寺；舍利塔重建为今日的八角五层石塔 |
| 明 | 洪武五年复名"栖霞寺"；永乐、万历南巡登临；1634 年张宏作《栖霞山图》（今藏台北故宫） |
| 清 | 乾隆五次南巡均驻跸栖霞，殿阁增建"冠绝东南"；咸丰年间毁于战火 |
| 近现代 | 宗仰、若舜相继中兴；1963 年鉴真像奉安于此；1979 年后大规模修复；2009 年 4A 级景区；2012 年入选"新金陵四十八景" |

### 3.3 必知看点（每个一句话，临场能讲）

- **栖霞寺**：中国四大名刹之一、三论宗祖庭，南朝延续至今的古寺。
- **千佛岩**：南齐始凿，294 龛、515 尊（后世续凿至约 700 尊）；大佛阁主尊无量寿佛高约 10 米（连座约 13 米）。
- **舍利塔**：隋诏始建、南唐重修，八角五层约 15 米，须弥座浮雕"释迦八相"；长江以南最古石塔之一，全国重点文物保护单位。
- **明征君碑**：唐高宗撰文、高正臣手书的唐代名碑；碑材里还藏着约 2.8 亿年前的海百合茎化石。
- **地名故事**：明镜湖与"彩虹明镜"、桃花涧、天开岩、小营盘遗址、乾隆御花园、陆羽茶庄、始皇临江处——每个名字都自带故事。
- **红叶**："栖霞丹枫"是金陵（新）四十八景之一；主力树种枫香、红枫、黄连木等；最佳观赏期约在 11 月；点位有霜红苑、桃花湖、太虚亭、枫林湖等。
- **张宏《栖霞山图》**：400 多年前的"栖霞山全景画"，国家一级文物、现藏台北故宫——做"古今对照"影像的天然素材。

### 3.4 游客旅程痛点表（选题弹药库）

| 阶段 | 游客的痛点 | AI 可以做什么 |
| --- | --- | --- |
| 行前 | 红叶什么时候最红？一天怎么走？带娃/带老人怎么走？ | 行前规划智能体；"红叶情报"播报 |
| 在场 | 千佛岩石刻看不懂"这尊是谁"；人多找不到点位；只有牌子上的碎片信息 | 现场问答、语音讲解、互动叙事 |
| 游后 | 除了照片没得带走；想找一首写栖霞的诗 | 生成"专属游历记忆"、声音明信片 |

### 3.5 赛前素材采集清单（踩点/远程都适用）

- 照片 ≥30 张：红叶特写 ×8、古建与石刻 ×8、路牌/导览牌 ×5、游客场景 ×5、细节纹理 ×4。
- 环境声 ≥3 段（每段 ≥30 秒）：寺内钟声/梵音、风过枫林、人流环境。
- 短视频 ≥5 段：山门、主路线、人群热区、舍利塔、红叶大道。
- 游客访谈 1–2 人（录音）：问"你此刻最想知道什么？""你会掏出手机查什么？"记下 3 句原话。
- 实用信息：景区开放约 7:00–17:00；红叶节期间票价约 80 元（淡季 50 元）；公交 206/207 等可达栖霞寺站——出发前用实时导航再核对一次。
- 提醒：拍人先打招呼；录音避开他人隐私对话；素材留存原始文件并备注来源。

## 7 新手最容易踩的 10 个坑

1. 贪大求全 → 砍到"48 小时能完成"。
2. 全程依赖海外服务 → 现场网络有风险，国内工具先备好。
3. 没有离线素材备份 → 演示前断网就完蛋。
4. 忽视"游客投票" → 作品不可围观、不可体验。
5. 忘了绑定栖霞山 → 变成通用 AI 作品，丢了文旅分。
6. 素材版权/肖像随手用 → 现场采风先打招呼、留出处。
7. 组队全押现场破冰 → 提前在群里找意向队友。
8. 两天都通宵 → 状态崩了讲不好 demo。
9. 展演即兴发挥 → 必须提前彩排。
10. 漏看录取邮件 → 10/24 前反复检查（含垃圾箱）。
