## 一、项目一句话

**栖霞山景区 AI 导游智能体（赛道二方向）**：行前帮游客规划路线；在场懂景、会讲、能带路；游后留下可延续的记忆。
本质是"一个以对话为核心、能调用工具的全能 agent"。

## 二、从聊天记录里继承的关键约束（已吵明白的）

1. **地图/定位只走官方 SDK/API**。逆向 SDK、爬登录态数据有合规风险（记录里提到"可能算破坏计算机信息网络罪"）——不碰。
2. **讲解数据必须自建**。地图厂商的讲解内容不开放 API，靠自己整理。
3. **定位精度现实**：GPS 漂移约 ±10m，之字山路两条路径间隔仅 20–30m。直接做"逐向导航"会翻车，必须"吸附 + 简化"。
4. **延迟是头号风险**：导航反馈不能等云端大模型"思考"。你们收敛出的"导航关思考、内容实时生成"方向正确。
5. **方向共识**：以 agent loop 为中心，所有功能外挂成 tool，上下文尽量少。
6. **开发方式**：模块区分清楚后可用多个 AI 并行写代码；能用"文件夹整理 + 提示词"解决的部分，不要专门开发。

## 三、推荐架构 v0

一句话：**Agent 管理解与内容，工具层管事实与动作，前端管体验；导航走确定性命中，讲解走生成式内容。**

```
[手机 H5 前端]
  对话区(文字/语音) │ 地图/导览小窗 │ 景点卡片 │ 记忆/回顾页
        │
[Agent 编排层]   系统提示(人设) + 结构化状态{位置/目标/路线/已访/偏好}
        │        LLM function-calling 循环（上下文只留最近几轮）
[工具层 6 件套]
  get_location   取定位 → 吸附到最近路径/景点（带置信度）
  list_nearby    周边景点列表（距离/方位）
  get_poi        讲解稿 + 音频（来自自建库）
  plan_route     起终点/途经点路线（官方步行规划；失败降级预设线）
  navigate_hint  下一步播报（模板 + TTS，不经过 LLM）
  save_memory / make_recap   游历记忆收集与回顾生成
        │
[底座] 自建 POI 库(JSON/SQLite) · 高德/腾讯地图 API · TTS/ASR · 本地缓存
```

### 3.1 前端（手机 H5）

- 形态：对话区 + 地图/导览小窗（记录里已定）+ 景点卡片 + 记忆页。
- 渠道：H5 扫码即用，游园会观众能直接玩；开发最快。
- 技术：高德 JS API（地图 + 定位 + 路线预览）；TTS 先用浏览器内置兜底、云端 TTS 升级音质。

### 3.2 Agent 编排层

- 单主 Agent，function calling 循环；系统提示定义人设与边界。
- 状态用结构化 JSON 维护（current_pos / target / route / visited[] / prefs），对话历史只留最近几轮——对应"上下文尽量少"。
- MCP 可把工具层再包一层（加分项）；主线用 function calling 实现（简单直接）。

### 3.3 数据层（内容护城河）

- 自建 POI 库 30–50 个点，字段：`id / 名称 / 坐标(GCJ-02) / 类别 / 讲解稿(150–300字) / 音频 / 图片 / 标签 / 邻近点 / 来源`。
- 来源三类：公开资料（百科/官网/新闻）+ 官方 POI API + 现场采集（踩点照片、录音、访谈）。
- 全量登记"来源｜版权｜授权"台账；不用登录态数据、不逆向。
- 讲解质量就是你们的内容得分点：Joey 主笔 + AI 提效 + 人工校核。

### 3.4 地图与定位层

- 高德开放平台为主线（JS API + Web 服务步行规划）；腾讯位置服务备选。
- 吸附算法：投影到最近主路径 + 距离阈值 + 上一位置平滑（简单实现即可）。
- 坐标系统一 GCJ-02，全链路不混 WGS-84。
- 导览模式：预设 2–3 条游览线（经典线 / 赏枫线 / 亲子线），"下一步提示"由路线序列直接生成。

### 3.5 记忆与回顾

- 简版：收藏点 + 一句话留言 + 照片 → 一键生成"我的栖霞山小报"（可加语音明信片）。
- 全自动相册整理：砍掉，留赛后。

### 3.6 降级与演示保障

- Demo 模式：模拟 GPS 轨迹回放；离线缓存音频/图片；录屏视频兜底；双网络（热点）预案。
- 游园会：单独做一个"30 秒体验页"（扫码 → 一个点位讲解 → 一个互动问题）。

### 3.7 创新点（回应"地图只占 1/3"）

- ① 对话式"懂景"：问"我现在看到的是什么"→ 定位 + 方位 → 讲解；
- ② 动态重规划："太累了，改走最短路线"→ 工具重排；
- ③ 游后记忆生成。这三件事是 agent 干得了、静态导览图干不了的。

## 四、48h 里程碑（粗排）

- Day1：跑通"问 → 答 → 讲解 → 轻导览"闭环；采风回填 POI 与素材。
- Day2：路线 / 记忆 / 游园会体验打磨 + 展演彩排。
