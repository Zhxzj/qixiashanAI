## 2 人性化设计提案（"同伴感"，按成本排序）

1. **先开口的向导**：到点自动讲解（A2）——从"问一句答一句的工具"变成"会照看的同伴"，这是全场最便宜的人性化。
2. **行前夜**：出发前一晚的规划对话（A1）——"被记挂"的感觉。
3. **回放小传**：海报生成前三行回放（A3）——游后情感峰值，"今天你走了 3 公里，在千佛岩站了很久"。
4. **疲劳与节奏感知**："累了""赶时间"→ 重规划 + 茶庄推荐 + 坡度提示 + 下山时间提醒；不劝、不催。
5. **光线感**：按时刻推荐拍照点（best_light）——"现在往霜红苑走，逆光正好"。
6. **不打扰原则**：默认安静、播报前轻提示、随时可打断、同点位不重复——话少本身就是"不像 AI"。
7. **老年友好**：默认大字号 + 高对比 + 语音优先（旺季主力客群），演示时顺带一句即加分。
8. **克制拟人**：不承诺"我会一直在"；不确定就说不确定（提示词已有）。剂量控制=高级感。
9. **称呼个性化**：首次 3 问（怎么称呼/偏好/体力），允许"直接进山"跳过。
10. **收尾不煽情**：海报递到手上，一句"这就是你那天的山。"停住。

## 附录 A：DeepSeek API 备忘（给 M2/M8 编码会话）

**基础**

- OpenAI 兼容：`base_url=https://api.deepseek.com`；beta（strict 模式用）：`https://api.deepseek.com/beta`。
- 模型名：`deepseek-flash`（V4.1-Flash；旧名 `deepseek-v4-flash`、`deepseek-v4-flash-vision-exp` 仍可用但已退役并入）。
- 能力：Vision ✓ / Tool Calls ✓ / JSON Output ✓ / 思考模式默认开启（effort 默认 high）/ 上下文 1M / 输出上限 384K。

**三个必知坑**

1. **思考模式默认开**：首 token 延迟高。导游对话主循环用非思考模式：OpenAI SDK 传 `extra_body={"thinking": {"type": "disabled"}}`（或 `reasoning` 版）；规划/海报编排可用 `reasoning_effort="low"`。
2. **带 `tools` 的请求：历史里必须完整回传每轮 `reasoning_content`，否则 400**。若全程禁用 thinking 则无此坑；若要 thinking+tools，实现必须保存回传。
3. **图片只能放在 `user` 消息**（system/assistant 里带图 → 400）。

**strict 模式（可选，Beta）**

- `/beta` + 每个 function 设 `"strict": true`；object 必须全部属性进 required + `additionalProperties: false`；支持 object/string/number/integer/boolean/array/enum/anyOf。服务端会校验 schema。

**Vision 细节（M8）**

- 格式 JPEG/PNG/GIF/WebP（按内容识别）；base64 内联（请求体 ≤48MiB）、外链（≤32MiB，URL ≤8192 字符）、Files API `file_id`（≤64MiB，可复用）。
- 单图自动缩放至 ~1300×1300 像素总量，计费上限 1024 tokens/张；单请求最多 600 张图。
- `detail`: low（缩到 512×，快省）/ high / original / auto。

**价格（off-peak；peak 翻倍；周末全 off-peak）**

- 输入 $0.15/M（cache miss）、$0.003/M（cache hit）；输出 $0.6/M。系统提示 + POI 常驻内容可吃缓存。

**其它**

- Chat Completions 不支持在对话中间插入 tool 调用（可插 system 消息）；如将来需要，用 Anthropic/Responses 格式。
