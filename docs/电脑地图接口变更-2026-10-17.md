# 电脑地图接口变更（2026-10-17）

用户已授权在原项目直接实施地图相关前后端修改，覆盖旧指令中另等设计审核的流程，并授权本任务跨 app/web 目录配套修改。本记录先于源码变更创建。

- 原 SSE、端口回退、演示 API 保留。新增 `/api/map/config`（GET/POST）、`/_AMapService/{path}`（GET）、`/api/map/mode`、`/api/map/route/start`、`/api/map/route/commit`、`/api/map/route/cancel`、`/api/map/location/start`、`/api/map/location`、`/api/map/stop`、`/api/map/facilities/preview`、`/api/map/facilities/import`（POST）和设施 GET。
- 新地图统一 GCJ-02；设备原始 WGS84 经高德转换一次后上传，含精度、时间、序列和导航票据。原草稿坐标未知，真实地图不展示。
- 地图选点由 JS 官方查询，起终点与完整 steps/path 经服务端校验后写入唯一会话 route。pending 请求票据防止过期算路覆盖新路线。
- LLM `plan_route` 在真实地图模式只提交待规划意图；页面查询并计算真实路线。主题/天气为建议而非服务已保证的道路属性；失败不回退草稿。
- 真实位置只在导航票据有效、15秒内、精度≤25米时参与判断；35米/8秒到点沿用，且讲解点需高德坐标匹配。页面隐藏/停止/重置清除判断。模拟控制先显式切换演示模式。
- 第三方路线与查询 POI 只保留当前进程内存，不写入会话SQLite；设施仅存用户提供、自有来源数据。正式许可与服务覆盖待真实凭据验证。
- 高德 JS Key 可由页面读取；安全密钥留本机配置，通过有限白名单代理附加。便携配置不能作为项目方秘密保护方案。不新增模型请求。

详见工作区根目录「电脑端真实地图与步行导航改造设计.md」。

- 最终补充：聊天持写锁时，新的地图模式/路线写请求快速409提示先取消或等待，不积压迟到写；定位/停止/取消路线不等模型锁。会话重置保持当前地图模式并清空选点。结构化工具结果中的坐标不落SQLite；用户与模型正文仍按原规则存档，可能包含位置信息。
