# 栖霞山小向导 · demo 使用说明（2026-10-15 版）

## 1 开机三件事

1. 双击根目录的 **`start.bat`**（首次自动建环境、装依赖，约 1 分钟；以后几秒）；
   免安装包版本则双击包里的 **start.bat**（无需任何环境）。
2. 浏览器会自动打开（没自动开就手动访问 <http://127.0.0.1:8017>）。
3. 点右上角 **API Key** 填入 DeepSeek Key → "保存并测试"。没有 Key 时，页面大部分能看，只有对话会提示先配 Key。

> 端口 8017 被占用时，改成 8018/8019 重启即可；`config.json` 只存本机。
> 关掉应用窗口就等于停止服务；要手动停就双击 `scripts\stop.bat`；卸载看《安装与卸载说明》。

## 2 三分钟演示（照着点就行）

在向导页点控制台里的 **▶ 走一遍剧本（3 分钟）**，它会自动：

1. 行前规划：小栖给出半天安排（plan_route）；
2. 上山：明镜湖 → 栖霞寺 → 千佛岩，每到一处**自动弹卡片 + 语音开口**；
3. 追问"讲讲最大那尊"（get_poi 详解）；
4. "累了、想看红叶、天气怎么样"（get_conditions + 天气感知重规划）；
5. "记住这里"（save_memory）；
6. 最后一步提示你 **去写今天的日记 →** 打开海报页。

海报页点 **用示例照片一键体验** → **生成三张候选** → 缩略图切换 A/B/C → **导出 PNG**。
每张候选右栏都会列出质检逐条结果（H1–H11）。

## 3 功能速查

### 向导页（/）

| 区域 | 能做什么 |
| --- | --- |
| 对话区 | 自由提问；空白键上方有一排"快问"按钮，一键代发常用问题 |
| 示意地图 | 三条路线 + 点位；走过的点会变成实心；当前位置是红点 |
| 天气与红叶 | 实时天气（Open-Meteo，免 Key）+ 红叶指数与建议 |
| 演示控制台 | 前进 50/200 米、跳点、重置、剧本模式 |
| 到点播报卡 | 播放/重播语音、"别念了"（静音后不再开口）、"讲讲这里"追问 |

### 海报页（/poster.html）

| 步骤 | 说明 |
| --- | --- |
| ① 上传照片 | 支持拖拽；自动读 EXIF 的 GPS，匹配到最近点位（400 米内） |
| ① 无 GPS | 自动调双目识别：本地颜色粗排 + Vision 直比参考图，给出候选点位 |
| ② 点位核对 | 每张照片可手动改点位（就是照片说明要写的那个地点） |
| ③ 演出记录 | 从向导页带来的到访点/留言；点"回放小传"打字机放三行 |
| 生成 | 三张候选（A 稳妥 / B 叙事 / C 惊喜），不同构图 + 不同色板 |
| 质检 | 溢出/对比/边距/字号/图片/留白/AI 标注逐条看 |
| 导出 | 2 倍分辨率 PNG，文件名带色板名；footer 固定"由小栖 AI 辅助生成" |

### 键盘

- 海报页：`1` `2` `3` 切换候选。向导页：无快捷键（防误触）。

## 4 演示前的检查清单

- [ ] `scripts\start_dev.bat` 能起来，`/api/health` 返回 `ok:true`
- [ ] Key 已配置且"测试连接"通过
- [ ] 向导页点过一遍剧本，浏览器允许音频自动播放（Chrome 里用 `chrome://settings/content/sound` 或允许本站点）
- [ ] 海报页示例照片能出三候选，QA 全绿
- [ ] 拔网测试：天气会回落本地记录、对话会报网络错——演示时保持联网（决策 #11）

## 5 常见问题

| 现象 | 处理 |
| --- | --- |
| 对话提示"还没配置 Key" | 右上角填 Key；`config.json` 里 key 写错时重新填即可 |
| 到点不播报 | 控制台"前进"两次（停留检测）；或点"跳到这里"后稍等 1 秒 |
| 没声音 | Chrome 拦了自动播放，点卡片上"再念一遍"；语音文件在 `app/audio/poi/` |
| 照片没认出点位 | 点"修改"手动指定；参考图库越全越准（`app/data/refs/`） |
| 质检有红项 | 换一批（换 seed）重渲；或点别的候选 |
| 端口冲突 | 关掉旧进程，或把 8017 改成 8018 重开 |

## 6 开发自测

```bat
.venv\Scripts\python scripts\smoke.py        :: 19 项端到端冒烟
.venv\Scripts\python scripts\boot_check.py   :: 真起服务再请求静态资源
node tools\test_poster_dom.mjs               :: 海报 6 构图 × 4 色板 × 1/3/6 张
```

生成素材（一次性）：

```bat
.venv\Scripts\python scripts\make_samples.py :: 合成参考图 + 示例照片
.venv\Scripts\python scripts\make_audio.py   :: edge-tts 预生成到点播报
```
