# 答辩口径备忘（2026-10-15）

评委常问的三类问题，提前把口径摆好。数字都来自当前仓库实测，演示当天按最新情况改。

## 一、"真能用吗 / 数据哪来的"

- 结构：本地 FastAPI（127.0.0.1:8017）+ H5 前端 + DeepSeek Flash（对话与工具调用）。
- 点位/路线是自建数据文件（当前 10 个点位、3 条线，骨架；目标 30–50），天气走 Open-Meteo 免 key。
- 到点讲解用预生成语音（edge-tts），断网也能放；对话与视觉识别需要联网（决策 #11）。
- demo 里示例照片与参考图为**程序合成**（无肖像、无版权风险）；赛前欢迎用真实采风照片替换 `app/data/refs/`。

## 二、"AI 会瞎编吗 / 成本多少 / 隐私呢"

- 讲解强制走 `get_poi` 工具检索，不在资料里的事实不编（提示词明令"不确定就说不确定"）。
- 单日演示成本约 ¥10–20（DeepSeek 官方价目，off-peak）。
- 合规：照片不落盘、不上图床；海报 footer 固定"由小栖 AI 辅助生成"；地图用手绘示意。

## 三、"48 小时怎么做到的 / 可复制吗"

- 全链路是"两个 AI 编码代理（Codex + Claude Code）+ 人把关"完成的：规格先行（SSOT 文档）、接口冻结、
  模块任务卡逐张交给编码会话，人只做决策与验收。
- 引擎可换皮：景点、路线、文风、配色全部走数据与 Skill 文件，不改代码就能换到别的景区。
- 演示顺序建议：30 秒讲"一人 + 两个 AI"→ 3 分钟 golden path（见《DEMO使用说明》）→ 收尾讲可持续孵化。
