# 栖霞山小向导：新手下载与使用

适用 Windows 10/11 64位电脑。免安装，无需自行安装Python。

## 下载与打开

1. 打开[最新版下载页](https://github.com/Zhxzj/qixiashanAI/releases/tag/v0.6.2-desktop)，展开页面下方的 Assets（附件）。
2. 下载 **QixiGuide-Windows-x64-v0.6.2.exe**，保存到桌面或自己的文件夹。不要下载“Source code”，那是开发者源码。
3. 先退出正在运行的旧版，再双击下载的EXE。第一次会自动准备本机运行缓存，稍候浏览器会打开小助手。
4. 在首页选择“AI问答”“地图导览”或“游记海报”。结束时点击页面右上角“退出应用”；只关浏览器不会停止本机服务。

此版本是免安装便携EXE，没有安装向导，不要求管理员权限。缓存和文字行程位于 `%LOCALAPPDATA%/QixiGuide/`。首次启动时间视电脑与安全扫描情况而定。

## AI问答怎么用

进入“更多 → 模型设置”，填写自己的DeepSeek API Key并测试连接。**每次重新打开或刷新页面都需要重新输入**；Key不保存到配置文件，不随安装包分发。使用AI会按模型服务商规则产生费用。

没有Key也可以查看地图、选择景点、规划本地步行路线、手动选择照片点位和使用模板日记。在线地图底图需要联网，GPS定位需浏览器允许；电脑定位不一定有手机GPS精度。

## 照片、路线与定位

地图中的主要景点支持点击聚焦、实景照片放大和两层介绍。本版包含12张用户授权实景照片及2张已有授权照片。厕所与大门为用户标注位置，路线沿本地OSM道路快照规划；未核实的入口末段、实时通行状态和现场定位精度请以景区标识为准。

## 打不开怎么办

- 下载后先确认文件名以 `.exe` 结尾且下载完整；可用同页SHA256SUMS.txt核对。
- 系统可能对未签名程序提示“未知发布者”。先核对来自本项目发布页及校验值，按自己的设备安全策略决定是否运行；不要关闭杀毒软件或组织安全策略。
- 浏览器没打开：再双击同一个EXE，或检查电脑默认浏览器设置。
- 仍失败：保留报错内容，通过仓库Issues反馈；不要贴API Key或包含个人资料的配置文件。
