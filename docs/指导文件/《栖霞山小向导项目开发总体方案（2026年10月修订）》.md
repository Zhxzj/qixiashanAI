## 2 总体架构（v2）

```
[窗口化浏览器 Edge/Chrome --app  →  http://127.0.0.1:8017 ]
  对话区(文字) │ 示意地图(SVG)+轨迹 │ 景点卡片 │ 日记/海报页 │ 演示控制台 │ kiosk 模式
        │  HTTP + SSE（同机回环）
[本地后端 FastAPI]
  ├─ Agent 循环（deepseek-flash · function calling · thinking 关闭）
  ├─ 快通道：navigate_hint 模板 + 构建期预生成 TTS 音频 + 到点自动播报
  ├─ 服务：定位吸附 / 路线（天气感知）/ 天气与红叶指数 / 海报文案 / 会话状态
  ├─ 数据：poi.json · routes.json · memory/recap · 适配缓存 · 调用日志(jsonl)
  └─ 静态托管 web/
        │
[外部依赖] DeepSeek API（运行时）· Open-Meteo 天气（运行时，免 key，有缓存兜底）· edge-tts（构建期）
[可选] 和风天气（有 key 时的升级选项）· Web Speech API（TTS 兜底）
```

### 3.4 plan_route（天气感知）

```json
{"name": "plan_route",
 "parameters": {"type": "object", "properties": {
   "to": {"type": "string", "description": "目标 poi_id"},
   "via": {"type": "array", "items": {"type": "string"}},
   "theme": {"type": "string", "enum": ["classic","autumn","family"], "default": "classic"},
   "consider_weather": {"type": "boolean", "default": true}},
  "required": ["to"]}}
```

行为：consider_weather=true 时读取 §3.10 条件服务，按路线属性打分（`slippery_risk / shade_ratio / indoor_points / total_steps`）：雨天偏好低滑、多点室内停留；高温偏好林荫；并按日落时间与 `best_light` 推荐光线点位。
返回：`{"route_id":"r_xx","theme":"autumn","distance_m":1680,"duration_min":45,
      "steps":[{"poi_id":"..","instruction":"..","stay_s":180}],
      "geometry":[[32.15,118.95],...],"fallback_used":false,
      "weather_note":"今天后山湿滑，已避开东侧石阶段","light_tip":"落日约17:20，可在凤翔峰看晚霞"}`

### 3.7 独立流程 make_recap（界面按钮触发，不走 Agent 循环）

输入：`{session_id, photos:[{file_id,lat,lng,ts,ref_poi?}], title?, seed?}`
流程：**回放小传（打字机三行）** → 时间轴组装 → 照片取色（palette_hint）→ DeepSeek 出 DesignSpec + 日记文案 → HTML+CSS 渲染器出 3 候选 → 质检 → 用户选定 → 导出 PNG
输出：`{replay_lines:[..], diary_md, timeline:[...], palette_hint:[..], candidates:[{design_spec, png}], poster_png}`

### 3.8 系统提示词 v2.1（独立文件）

见《小栖人设与语言风格工作守则》（v2.1）：对话规则 + 去 AI 味检查点 + 古风剂量 + **主动开口/不打扰/回放小传**三段新增。直接抄进 `app/agent/prompts.py`。

（若 Flash 的 tool calling 不稳定，降级方案：JSON 指令模式——提示词约束模型每轮输出 `{"tool":"..","args":{..}}` 或 `{"reply":".."}`。）

### 3.9 照片无 GPS 时的场景识别（M8 · v2 两轮直比）

- **依据（已核实）**：Vision 单图计费上限 1024 tokens（自动缩放到约 1300×1300 像素总量），单请求最多 600 张图，图片只能放 user 消息。→ 不需要"编号拼图"。
- **构建期**：`scripts/collect_refs.py` 按点位抓参考图（每点 10–20 张）；过滤：≥600px、明亮度、pHash 去重、可见人脸粗筛；优先官方图与自采图；来源写入 `docs/sources.csv`。
- **运行期（两轮）**：①用户照片 + 文字候选清单（各点位一两句特征）→ 模型报 top-3；②用户照片 + top-3 参考图（4 张图一次请求）直接比对 → `{poi_id, confidence, evidence}` → 界面弹"像在千佛岩拍的？"供确认/修改。
- **保底**：低置信度 → 手动点选地图。
- **合规**：见决策 #23。

### 3.10 天气与红叶指数（get_conditions）

```json
{"name": "get_conditions",
 "description": "查询当前天气、未来天气趋势与栖霞山红叶指数，用于行程建议。",
 "parameters": {"type": "object", "properties": {
   "days": {"type": "integer", "default": 1, "description": "未来天数（1-3）"}}, "required": []}}
```

返回：`{"weather":{"now":{"temp_c":22.7,"text":"多云","wind":"微风"},"today":{"min":15,"max":24,"rain_prob":20,"sunset":"17:22"},"forecast":[..]},
      "red_leaf":{"score":72,"text":"红了七成","trend":"未来三天降温，会再红一些"},
      "advice":["午后有雨的概率小，霜红苑适合去","山顶风大，外套带上"]}`

- **天气源**：Open-Meteo（免 key；本机已验证可达）`api.open-meteo.com/v1/forecast`；服务端缓存 15 分钟；失败→最近缓存→`app/data/manual_conditions.json` 人工兜底。可选升级：和风天气（有 key 时）。
- **红叶指数（自研公式，代码注释中保留推导）**：
  `score = clamp(60 × date_curve + 40 × cold_units_norm, 0, 100)`
  - `date_curve`：10-15 → 0.35；10-25 → 0.6；11-01 → 0.8；11-15 → 0.95；之后缓降。
  - `cold_units_norm`：过去 7 天 `Σ max(0, 12 − min_temp)` 归一化（0–1）。
  - 人工修正：`manual_conditions.json` 里 `red_leaf_override` 优先（现场实况）。
  - 文案映射：<25 未红 / 25–45 初红 / 45–65 半红 / 65–85 七成（最佳） / >85 正红。
- **用途**：Agent 回答天气/红叶问题；plan_route 天气感知；海报 kicker 可带"晴/阴"字样；展演时"结合天气推荐路段"是演示点。

## 4 数据模型 v1

### 4.1 poi.json（目标 30–50 个点位）

```json
{"poi_id": "qianfoyan", "name": "千佛岩", "category": "古迹",
 "coord": [32.1541, 118.9592], "tags": ["南朝", "石刻"],
 "text_short": "..（80字）", "text_full": "..（200–300字）",
 "facts": ["294龛515尊", "南齐始凿"],
 "best_light": "上午", "photo_spot": "大佛阁平台",
 "attrs": {"slope": "中", "shade": "低", "indoor": false, "surface": "石阶"},
 "audio": "audio/poi/qianfoyan.mp3", "images": ["img/qianfoyan_1.jpg"],
 "neighbors": ["舍利塔", "大佛阁"], "sources": ["百度百科·千佛岩", "现场采集 2026-10-17"]}
```

写作规范：先事实后故事；生僻字注音；每点位至少 1 个"可被记住的钩子"。

### 4.2 routes.json

3 条预设线：`classic`（山门→明镜湖→栖霞寺→千佛岩→舍利塔→红叶谷）、`autumn`（赏枫专线）、`family`（亲子短线）。
每条：`{route_id, name, total_m, attrs:{total_steps, shade_ratio, indoor_points, slippery_risk}, points:[{poi_id, instruction, stay_s, geo_idx}], geometry:[[lat,lng],...]}`
`slippery_risk`：1–5（雨天权重用）；`shade_ratio`：0–1（高温权重用）。

### 4.3 memory / recap

`memory` 见 §3.0；`recap`: `{session_id, replay_lines, diary_md, timeline:[{ts,poi_id,text}], photos:[{file_id,poi_id,lat,lng}], palette_hint, design_spec, poster_png}`

### 4.4 来源台账（docs/sources.csv）

列：`poi_id | 字段 | 来源类型(公开/官方API/现场) | 来源URL或备注 | 采集日期 | 授权说明`
天气数据行注明：Open-Meteo（CC-BY 4.0，需署名）→ 页面页脚放"天气数据 © Open-Meteo"。

### 4.5 人工兜底文件（app/data/manual_conditions.json）

```json
{"red_leaf_override": null, "note": "现场实况：霜红苑七成（2026-10-31 人工更新）",
 "fallback_weather": {"temp_c": 18, "text": "多云", "sunset": "17:20"}}
```

## 12 附录 A：DeepSeek API 备忘（给编码会话）

- OpenAI 兼容 `base_url=https://api.deepseek.com`；strict 模式用 `/beta`；模型名 `deepseek-flash`。
- 能力：Vision ✓ / Tool Calls ✓ / JSON ✓ / 上下文 1M / 输出 ≤384K；思考模式默认开启（effort 默认 high）。
- **坑 1**：思考模式拖慢首 token → 主循环 `extra_body={"thinking": {"type": "disabled"}}`（规划/海报编排可用 `reasoning_effort="low"`）。
- **坑 2**：带 `tools` 且开 thinking 时，历史必须完整回传 `reasoning_content`，否则 400。
- **坑 3**：图片只能放在 `user` 消息（system/assistant 带图 → 400）。
- Vision：JPEG/PNG/GIF/WebP；base64 ≤48MiB 请求体 / 外链 ≤32MiB / Files API ≤64MiB；单图 ≤1024 tokens；单请求 ≤600 图；`detail: low/high/original/auto`。
- strict（Beta）：schema 里每个 object 全部属性 required + `additionalProperties:false`；支持 object/string/number/integer/boolean/array/enum/anyOf。
- 价格（off-peak；peak ×2；周末全 off-peak）：输入 $0.15/M（cache miss）· $0.003/M（cache hit）· 输出 $0.6/M → 演示单日约 ¥10–20。
