# 关于项目指导文件体系的通知

（枫客松 · 栖霞山小向导项目组　2026年10月15日）

各有关方面：

为规范本项目文件管理，现将现行指导文件体系明确如下，请遵照执行。

## 一、现行有效文件（三件套，编码代理必读）

1. **《栖霞山小向导项目开发总体方案（2026年10月修订）》**——总纲（SSOT，内部版本 v1.2）。全项目唯一事实来源；派发编码任务时随任务卡一并提供。
2. **《小栖海报生成工作管理办法（试行）》**——海报生成规范（内部版本 v0.1）。
3. **《小栖人设与语言风格工作守则》**——小栖人设与文风（内部版本 v2.1）。

配套备赛文件：《枫客松备赛学习手册（内部资料，注意保存）》《枫客松备赛工作安排（2026年10月版）》。**时间线一律以总体方案 §10 为准。**

## 二、参考与存档文件

- 《关于项目优化创新工作的调研报告（征求意见稿）》——调研结论已并入三件套，保留作细节索引。
- 《项目架构座谈会纪要（存档）》——历史文件，已被总体方案替代，仅作背景。
- 微信记录提取、`work/research/` 研究素材：原始资料，不作指导依据。

## 三、使用要求

1. 开发任务按"**总体方案 + 对应办法/守则 + qixi-guide/AGENTS.md**"一体交付，缺一不可。
2. 文件名称以本通知为准；今后修订，在文件名括号内注明版本或日期。
3. 对外引用（展演稿、README、报名材料）一律使用上述规范名称。
4. 本通知本身不构成规范；如有冲突，以总体方案为准。
