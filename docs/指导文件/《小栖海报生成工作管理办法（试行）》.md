# 小栖海报生成工作管理办法（试行）

> 用途：枫客松作品《栖霞山小向导》的"游后日记海报"生成规范。
> 给谁看：① 运行时引擎（M6 模块照此实现）；② 编码代理（整文件丢给 Codex / Claude Code 当实现说明）。
> 核心原则：**不定模板，但要稳定**——"受限生成词汇 + 渲染器负责几何 + 质检闸门"。LLM 只做编排和文案（输出 DesignSpec JSON），渲染器把设计规格变成版面，质检层保证每张都过门槛。
> 内部版本：v0.1（生成式 · 不定模板）。关联：《栖霞山小向导项目开发总体方案（2026年10月修订）》§3.7 / §8；文案文风见《小栖人设与语言风格工作守则》。
> v0.1 变更（2026-10-15）：新增照片取色联动（§3.4）、手卷变体（§2.5 第 7 条）、footer AI 标注（H11）、来源戳说明（§2.6）；实现仍锁定 HTML+CSS。

## 1. 质量标准（先定义"什么叫好"）

### 1.1 硬规则（任一不过 → 自动换种子重渲，最多 2 轮）

| 编号 | 规则 |
| --- | --- |
| H1 | 无溢出：任何文本不溢出容器；标题超长自动降级或断行，断行不切断词组 |
| H2 | 对比度：正文/背景 ≥ 4.5:1；大字号标题 ≥ 3:1 |
| H3 | 边距：四边留白 ≥ 画布宽 4%；主内容不贴边、印章不压角（离边 ≥ 6%） |
| H4 | 字号纪律：只用 6 级阶梯（@1080 宽：96 / 72 / 52 / 36 / 28 / 20）；正文 ≥ 28 |
| H5 | 字体纪律：≤ 2 个字族（标题文楷 + 正文宋体）+ 1 个装饰字 |
| H6 | 色彩纪律：从 §2.1 色板选 1 套；除中性色外 ≤ 3 色；点睛色面积 < 5% |
| H7 | 图片：不变形、不拉伸；统一处理（圆角/白边/和纸框三选一）；源图短边 ≥ 600px |
| H8 | 主视觉唯一：全页只有一个"第一眼焦点" |
| H9 | 留白：背景可见面积 ≥ 35%（含纹理） |
| H10 | 文案：遵循《系统提示词 v2》；标题 ≤ 12 字；单句 ≤ 40 字；全页总字数 ≤ 180 |
| H11 | 标注：footer 槽位固定含一行小字"由小栖 AI 辅助生成 · 日期"（合规要求；用最小字级，不抢视觉） |

### 1.2 评分（40 分制，≥ 32 才交付）

8 个维度 × 5 分：层次 / 平衡 / 节奏 / 色彩 / 图文关系 / 主题契合 / 记忆点 / 完成度。低于阈值自动重生成。

## 2. 栖霞山视觉语言（核心资产）

### 2.1 四套色板（每套 6 个角色：背景 / 纸面 / 主 / 辅 / 点睛 / 墨字）

| 色板 | 背景 | 纸面 | 主 | 辅 | 点睛 | 墨字 |
| --- | --- | --- | --- | --- | --- | --- |
| 丹枫（默认） | #A63A2B | #F7F0E4 | #C2492F | #6E2A20 | #D9A441 | #2E2622 |
| 赭墨 | #F3EDE0 | #FBF7EF | #8C5A2B | #4A3A2A | #B23A2E | #2B2620 |
| 烟岚 | #DFDCD4 | #F4F2EC | #5B6E6A | #94A69E | #C2492F | #333B38 |
| 月白 | #F7F5F0 | #FFFFFF | #3E4A5B | #A8B0BD | #D9A441 | #262C36 |

（延续招募海报"橙红 + 米白"的基因做丹枫；其余三套用于非红叶季、阴天、夜间场景的情绪平衡。）

### 2.2 母题库（10 个，SVG，全部本地）

鸡爪槭叶 / 枫香叶 / 落叶片组（3–5 片）/ 山形（双峰，可断线）/ 舍利塔剪影 / 佛龛拱形 / 千佛点阵 / 江水波纹 / 云纹 / 印章框。

- 每枚两种笔触：实心剪影 + 单线线稿；统一 24px 网格，最大 480px，单文件 ≤ 8KB。
- 制作方式（一次性）：AI 生图出笔触参考 → 人工描摹或矢量化 → 统一笔宽与风格。**母题是素材，不进每次生成链路。**

### 2.3 字体

标题/引文：霞鹜文楷（OFL）；正文：思源宋体；数字/西文：EB Garamond。全部用 fonttools 子集化后本地内置。

### 2.4 纹理

宣纸噪点（SVG fractalNoise）/ 朱砂印泥 / 轻颗粒渐变 / 纸胶带（全页 ≤ 2 处）。

### 2.5 六种构图文法（每次生成组合其中 1 种 + 2 种母题）

1. **山门式**：大图占 55–60% 高，竖排大标题，印章 1 枚，底部一行小字（日期 + 点位数量）。
2. **卷轴式**：左竖栏（标题/日期/编号）+ 右大图 + 下方 1–2 张小图，边缘 1 枚母题线稿。
3. **时间轴式**：竖向轴线 + 3–5 个节点（点位名 + 一句话 + 小图交替），顶部标题区。
4. **拼贴式**：3–6 张照片散置（统一白边/圆角 + 手写感标注），2–3 枚枫叶点缀。
5. **诗笺式**：大量留白，居中竖排短句（≤ 16 字）×1–2 处，小图或印章 1 枚，底部信息条。
6. **地图式**：路线轨迹线稿贯穿全页，照片锚在点位，标距离/时间，起点终点醒目标记。
7. **手卷式（P2 彩蛋）**：时间轴式的长卷变体——画布 1080×2400+，卷首题签 + 时间轴贯穿 + 卷尾印章；呼应张宏《栖霞山图》——四百年前有人为这座山画过长卷，今天游客也有自己的一卷。（画布高度可变量：标准 1620 / 手卷 2400）

### 2.6 内容槽位与照片处理

- 共用槽位：`title / kicker(日期·天气感) / hero / subs[] / captions[] / quote? / route_info / seal / page_no / footer`
- 来源戳（P1，可选）：caption 引用了讲解要点时，允许在其后跟一枚小字来源（如"据《摄山志》"）；每页 ≤ 2 处，样式低调。
- footer（H11）：固定含"由小栖 AI 辅助生成 · {date}"，由模板统一注入，不依赖 LLM 输出。
- 照片 1–6 张：1 张走"山门式/诗笺式"；3 张走"卷轴式/时间轴式"；6 张走"拼贴式/地图式"。
- 裁剪形状：rect / 拱形（佛龛） / 圆形 / 拍立得白边；同一张海报内形状 ≤ 2 种。
- 统一色调：轻微降饱和 + 暖偏 3%，避免照片色调打架。

## 3. 生成流程

### 3.1 管线

```
游历数据包（照片+游踪+收藏+留言）
  → ① 编排：选照片、提炼 3–6 条 caption（引用到访点位讲解要点）
  → ② DesignSpec（LLM 输出 + schema 校验；失败重试 ≤2）
  → ③ 渲染：本地 HTML/CSS 渲染器（离屏 1080×1620 舞台）
  → ④ 导出：html-to-image（pixelRatio 2）→ PNG
  → ⑤ 质检：硬规则 + 评分；不合格换 seed 重渲
  → ⑥ 三候选（A 稳妥 / B 叙事 / C 惊喜，色板各不同）→ 用户选 / 换一批
```

> 实现已锁定为 **HTML+CSS**：不用 Canvas 手绘排版、不用 AI 整图；字号/间距/对比/溢出都能直接查 DOM，改版不需重画。工程要点见 §3.5。

### 3.2 DesignSpec JSON（LLM 唯一的输出物；渲染器不接受非法值）

```json
{
  "canvas": {"w": 1080, "h": 1620},
  "grammar": "mount|scroll|timeline|collage|poem|map",
  "palette": "danfeng|zhemo|yanlan|yuebai",
  "motifs": [{"id": "maple_leaf", "style": "line|solid", "x": 0.82, "y": 0.12, "scale": 0.14, "rot": -18}],
  "photo_layout": [{"file": "p1.jpg", "role": "hero|sub", "crop": "rect|arch|circle|polaroid", "slot": "top|mid|bottom"}],
  "type": {"title": "……", "kicker": "2026.10.31 · 晴", "captions": ["……"], "quote": null, "seal": "栖霞·丹枫"},
  "meta": {"date": "2026-10-31", "poi_count": 7, "route_m": 1680, "page_no": "No.001"},
  "seed": 20261031
}
```

约束：motifs ≤ 3；captions ≤ 6；文案走《系统提示词 v2》文风。LLM 严禁直接写 CSS/HTML。

### 3.3 变化引擎与三候选

- seed 决定取样组合（grammar × palette × motif × crop），同一数据两次生成版式不同且都合规。
- 三候选固定策略：A = 山门式/卷轴式（稳妥）；B = 时间轴式/地图式（叙事）；C = 诗笺式/拼贴式（惊喜或活泼）。
- "换一批" = 新 seed 重走管线（保留用户已选照片与文案）。

### 3.4 照片取色联动（v0.1 新增 · P1）

- **目的**：海报的色，取那天的光——从用户照片中提取主色，让海报与当天实拍同温。
- **流程**：①渲染前在浏览器内把 1–6 张照片画到离屏 canvas（短边缩到 ≤256px）；②`getImageData` + 颜色量化（16 桶直方图聚类），剔除过亮/过暗像素；③取前 3 主色；④与当前色板的 6 个角色（背景/纸面/主/辅/点睛/墨字）做 CIELAB 距离匹配：
  - 最近距离 < 阈值（约 ΔE 12）→ 允许用照片主色**替换点睛色 accent**，写入 `palette_hint.accent_override`；
  - 否则仅记录 `extracted`（`accent_override: null`），不动色板。
- **约束**：只允许替换 accent 一个角色；替换后 H2 对比度与 H6 色彩纪律照常质检，不过即回退原色板。
- **接口**：取色属渲染管线的机械步骤（render.js 执行），**不是** LLM 输出；DesignSpec 中 `palette_hint` 仅供记录与调试。

### 3.5 HTML+CSS 实现要点（v0 锁定）

- **舞台**：单节点 `#stage`，固定 1080×1620；预览用 `transform: scale()` 缩放，导出前重置为 1。
- **模板**：`renderer/render.js` + 每语法一个模板函数（`grammar-*.js` 共 6 个），输入 DesignSpec、输出 DOM；全部用 DOM + class，不用 Canvas 绘制。
- **样式**：`palettes.css` 用 CSS 变量定义 4 套色板（`[data-palette="danfeng"] { --bg:…; --paper:…; --primary:…; --secondary:…; --accent:…; --ink:… }`）；`type.css` 定义 6 级字号阶梯（t1–t6）；`layout.css` 定义 12 栏栅格与 4% 安全边距。
- **字体**：本地 `@font-face`（子集化 woff2）；导出前 `await document.fonts.ready`，避免首张图字体回退。
- **导出**：`toPng(stage, { pixelRatio: 2, width: 1080, height: 1620 })`；失败回退 snapdom。
- **质检钩子**：文本节点 `data-qa="text"`、图片 `data-qa="img"`；检查脚本在浏览器端运行（溢出/重叠/边距/字级/图片）。
- **取色**：`render.js` 中 `extractPalette(imgs)`（离屏 canvas）→ `applyHint(spec, hint)`；accent 覆盖通过覆盖 CSS 变量 `--accent` 注入。
- **标注**：footer 由模板统一渲染"由小栖 AI 辅助生成 · {date}"（H11），不依赖 LLM。
- **禁项**：不内联远程图片 URL（一律本地缓存图）、不用远程字体、CSS 里不写死色值（只允许引用变量）。

## 4. 质检

### 4.1 自动检查（代码级）

1. 溢出：所有文本节点 `scrollHeight <= clientHeight + 1`
2. 重叠：非白名单元素矩形相交检测
3. 对比：WCAG 公式计算前景/背景
4. 边距：元素 bbox 离边 ≥ 4% 画布宽
5. 字级：无低于 20px 文字；正文 ≥ 28
6. 图片：短边 ≥ 600px；无拉伸（等比裁剪）
7. 色彩：非中性色 ≤ 3；点睛面积估算 < 5%
8. 密度：背景像素采样估算空白率 ≥ 35%
9. 标注：footer 存在且包含"AI 辅助生成"（H11）

### 4.2 LLM 审片（可选加分）

候选截图 → 多模态模型回答："哪里空/挤/花？像不像 AI 拼的？"→ 输出修改建议 → 允许自动微调一次（换母题位置 / 换照片裁切 / 降点缀色）。

### 4.3 翻车案例库（回归用）

标题压脸 / 中央拥挤 / 照片色调打架 / 母题过大喧宾 / 竖排断词 / 印章压角 / 文字贴边 / 中英数字字体乱配。

## 5. 工程与验收

- 目录：`web/poster/skill/{SKILL.md, design-spec.schema.json, renderer/, grammars/, palettes.css, motifs/, textures/, fonts/, samples/}`
- 性能预算：单张渲染 + 导出 ≤ 8 秒（本机）；三候选 ≤ 25 秒。
- 样本回归：6 语法 × 4 色板各 1 张样张（24 张），改渲染器后跑截图对比。
- 验收：3 组真实数据（1 图 / 3 图 / 6 图，含无 GPS 场景）× 3 候选 × 2 轮 → 全部过硬规则、评分 ≥ 32、候选间版式差异明显；**取色联动：同一组照片在 4 色板下实测 accent 命中 ≥ 1 次且对比质检通过**。

## 7. 明确不做

- 不做固定模板库：每次由 grammar × palette × motif × seed 组合生成。
- 不让 AI 图像直接生成整张海报（文字易崩、不可控）；AI 生图仅用于制作母题/底纹等一次性素材。
- 不引入云端渲染依赖：导出在本地浏览器完成。
- 不用 Canvas 手绘排版：版式一律 HTML+CSS（质检直接查 DOM；Canvas 仅用于必要的图片后处理）。
