# 页面Key与返回首页契约
用户要求删除旧Key、每次进入重填、每页左上角返回首页。Key不写磁盘、浏览器存储、URL或日志；只在进程内按页面随机能力ID隔离。新页面/刷新产生新ID，iframe只共享父页面ID，不共享密钥。关闭页面主动forget，异常关闭的孤立Key在进程退出或12小时闲置清除。
模型鉴权必须发送至既有DeepSeek官方API；禁止把Key发往代码托管或第三方埋点。本次不推送GitHub。
/api/config改为内存启用；/api/config/forget只清除对应页面能力。既有聊天/照片/日记通过请求context读取该页Key，原业务流程保持。原持久化失败测试调整为内存模式验证。
返回首页只恢复首页呈现，不重载文档、不清聊天/路线/照片/Key；重开或刷新才需重填。独立海报页也有返回入口。
