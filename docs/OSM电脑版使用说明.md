# OSM电脑版使用说明（0.4.4）

双击`dist/栖霞山小向导.exe`，无需安装Python或填写地图Key。更新前退出旧版；当前本机已启动0.4.4。问答模型需另行配置。

1. 地图默认显示红色景点、12个紫色无编号厕所、2个绿色大门。大门只使用用户黄色标记位置；不显示旧OSM北门或未命名门。没有“公开厕所候选”图层。
2. 拖动、滚轮/按钮缩放；点“回到景区”全览。景点、道路、厕所、大门图层可独立切换。用户要求删除的地图状态行、两个“查看全部”按钮和数量统计已移除。
3. 点击标记或搜索结果聚焦放大，旁边显示详情。景点照片下方直接显示大字简介及小字详述；照片来源、作者和许可在默认折叠资料内，大图无下方说明。查看详情不自动改终点。
4. 在详情明确设起终点，也可图上选点、添加途经、避开已标注台阶，再点步行规划。路线沿内置OSM路网，不连通时提示失败；设施入口未核实时只规划到附近道路，分别标明路网终点和直线间隔，不画虚假连接线，不播报已到设施。
5. 定位需浏览器及Windows授权，有效精度不超过25米、样本不超过15秒等条件满足后才实时判断。没有GPS的电脑不保证米级；拒绝、低精度或过期时可用手动起点。坐标全程WGS84，不转换高德坐标。
6. 点“大门与厕所校对”或设施详情内校对按钮，地图点选→预览→明确保存。取消/Esc不保存，恢复仅影响此点。保存在`%LOCALAPPDATA%/QixiGuide/config/map-annotations.json`，可导出备份。厕所不编号，请直接点击目标图标再校对，避免选择同名点混淆。
7. 照片资料和设施均来自有记录的数据。截图配准只还原用户标记，不等于现场测量；南侧大门离现有路网终点约30米，入口接入仍待核对。路网未通过现场全覆盖和开放核实。
8. 在线底图需要网络，使用OSM公共瓦片；断网时内置道路、景点和本地算路仍可用。公共瓦片服务不保证持续可用。退出请点“退出应用”，关闭浏览器不会停止服务。

原始OSM归档为225段道路、1809节点及周边地标，保留全部来源；活动地图接口不再下发3个公开厕所候选。用户截图新增标记独立保存，没有改变路网，也不使用旧导览牌补点补路。

本轮完整修改、构建、检查及未验证项见《电脑端大门与紫色标注厕所改造设计》第13节。当前实际地图与两门路线截图在`dist/approved-map-exe-reports`。
