# 安装与卸载说明（给别人的机器 / 评审机）

> 不想让对方装 Python？看《打包与分发调研.md》走**免安装版**（便携 Python 方案）：
> 构建 `scripts\build_portable.bat`，产物双击即用、零依赖。

## 一、能直接发吗？看对方机器有没有 Python

现在的 `start.bat` 会自动建环境、装依赖，所以：

| 对方机器 | 能不能跑 |
| --- | --- |
| 装过 Python 3.10+（装的时候勾了 "Add python.exe to PATH"） | ✅ 双击 `start.bat` 即可，首次约 1 分钟 |
| 没装 Python | ❌ 会提示先去 python.org 装（故意不自动装 Python，避免改对方系统） |
| 完全没网 | ❌ 首次装依赖需要网。办法：在联网机器上先跑一次，把整个文件夹（含 `.venv`）拷过去 |

## 二、给对方的标准动作（三步）

1. 把 `qixi-guide` 整个文件夹压成 zip 发过去（含 `.venv` 更省事，约 100–150MB）；
2. 对方解压后双击根目录的 **`start.bat`**（首次自动建环境 + 装依赖，之后直接启动）；
3. 浏览器自动打开；第一次要填 DeepSeek API Key（页面右上角）。

> 不想让对方装 Python？用免安装包：`scripts\build_portable.bat` → 产物 `dist\枫客松-小栖-demo-free\`
> 里双击 **start.bat** 即可（自带解释器）。详见《打包与分发调研.md》。

## 三、文件里是什么

| 文件 | 作用 |
| --- | --- |
| `start.bat` | 一键启动：找 Python → （首次）建 venv + 装依赖 → 选空闲端口 → 起服务 → 开浏览器 |
| `scripts\stop.bat` | 停掉后台服务 |
| `scripts\doctor.bat` | 环境自检（Python/依赖/端口/网络/Key/素材一次性体检） |
| `scripts\fix_startup.bat` | 启动异常时的修复模式：把旧 `.venv` 挪开重建一次 |
| `uninstall.bat` | 卸载：停服务 + 删快捷方式 |

> 注：`.bat` 文件保持纯 ASCII（cmd 按本地代码页解析），所有中文提示由 Python 打印。
> 启动过程会写日志：`startup.log`（程序目录；目录不可写时在 `%LOCALAPPDATA%\QixiGuide\`）。
> **如果双击后窗口一闪而过或没反应，先看这个日志**，把内容发我即可定位。

## 四、关于"后台进程"的三件事

1. **服务是同一个进程**：uvicorn 不开子进程，服务就是一个 `python.exe` / `pythonw.exe`。
2. **关掉应用窗口 = 停止服务**：启动器用 `--app` 方式打开浏览器，并等它关闭；窗口一关，进程退出，
   服务随之停止。
3. **兜底手段**：`scripts\stop.bat`（按端口找 python 进程再停，不碰别的程序）；
   极端情况下任务管理器结束 `pythonw.exe` 也行。

## 五、卸载（干净的）

双击 `uninstall.bat`，它会：停服务 → 删桌面/开始菜单快捷方式。

程序本体是**绿色文件夹**，不写注册表、不装系统服务、不加开机启动。所以：

- 数据都在文件夹里：`config.json`（API Key）、`app\data\`（点位/照片/参考图）、`app\audio\`（语音）；
- 想彻底清掉：直接删除整个 `qixi-guide` 文件夹即可（卸载脚本不会帮你删数据，是故意的——
  采风照片和讲解初稿还在里面）。

> 开发机上的 `.venv\`、`tools\node_modules\` 都是可再生成的，删了不影响数据。

## 六、对方机器没装 Python：用免安装包（已可用）

构建一条命令（在你的机器上跑，需要一次联网；之后可离线重打）：

```bat
scripts\build_portable.bat
```

产物：`dist\枫客松-小栖-demo-free\`（连 `runtime\python` 一起打包，对方零依赖），
双击里面的 **启动.bat**（或 `start.bat`）即可。压成 zip 发给对方，解压后双击。

> 为什么不是 PyInstaller：开发环境是 Python 3.14，PyInstaller 目前没有对应的轮子；
> 便携 Python（python-build-standalone）方案同等效果、风险更低。详见《打包与分发调研.md》。

> 注意：杀毒软件有时会对"未签名的新 .bat/新解压的 exe"拦一下，属正常情况；
> 如遇提示选"仍要运行"。解压时请先解压到普通文件夹，不要在压缩包预览里直接双击。
