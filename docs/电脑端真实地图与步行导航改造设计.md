# 电脑端真实地图与步行导航改造设计

版本：v1.2（Leaflet＋OpenStreetMap 电脑版已实施；现场精度与通行验收待完成）；日期：2026-10-17。

当前默认方案以第10节为准：按用户后续授权改用无需地图Key的Leaflet＋OpenStreetMap；第1—9节的高德选型及验收记录保留为历史。

## 1. 授权与范围

用户确认在 `D:\qixiashan` 原项目直接实施，设计与实际记录一并交付，不再另等设计审核。仅电脑端，安卓项目不动；不推送、不购买服务。定位按实测精度与降级验收，不承诺无GPS电脑米级导航。高德优先，两张现场牌图只辅助核对名称及道路关系，未知坐标不上真实导航图。

## 2. 现状与主要问题

基线提交25e2115，跟踪文件干净。原地图在web/js/app.js中以SVG线性拉伸经纬度，每2秒重建；未绘制当前规划geometry。原定位默认sim/confidence0.9，不是真实设备定位。10景点、3路线无已知坐标系，不能叠加到高德假装核实。原35米/8秒到点缺少精度、新鲜度、后台及跳变判断。

## 3. 技术方案

高德JS API2.0 + PlaceSearch + Walking；浏览器watchPosition输出WGS84，通过AMap.convertFrom转换一次GCJ-02。地图实例保持，增量更新点/线/精度圈；默认二维地图，支持缩放、拖动、搜索、起终点、全览和分类开关。查询候选只限景区工作范围并显示来源；点选未命名坐标明确标注，不能冒充景点。

界面：聊天保留左栏；右侧扩大为地图主工作区，顶部状态/配置/重试，中部真实底图，下部搜索列表、起终点、规划卡片、导航开关。空厕所层说明待补。加载失败显示配置或重试，其他功能不白屏。演示另以明确模式显示原SVG，未知坐标不进入真实底图。

地图客户端提交起终点取得route request_id及会话generation，再调用官方Walking，完整拼接steps/path，携票据提交唯一后端route；失败清除pending，不保留旧导航判断。快速规划旧响应409。后端校验坐标、连续性、端点、距离、数量和步骤。服务返回不等于现场开放核实。

LLM工具在真实模式提交pending意图，不在草稿路网算路；页面按准确的内部景点名称查官方候选，存在歧义则要求地图选择。主题/天气仅保留建议，不伪称高德已按遮阴或红叶优化；途经点逐段且失败不补直线。设备定位经度纬度与现有内部[lat,lng]顺序在适配层统一。

## 4. 定位与导航状态

导航启动生成票据；generation/request_id/票据和递增seq防止停止、重置、迟到请求复活导航。样本≤30秒才接收，判断门槛≤15秒、accuracy≤25米，明显跳变暂停判断；15m/s上限并考虑两端精度。页面隐藏及停止立即清watchPosition、停止票据；后端无更新即过期。恢复需用户重新启动。

沿当前真实geometry投影，显示进度与偏离；偏离超过max(35米,2×accuracy)持续8秒提示，不自动收费重算。到终点要求实际距离和精度同时合格，不能仅靠投影到末端判已到达。35米/8秒讲解复用只针对服务结果明确对应的内部景点，样本间隔过长重置驻留。低精度可显示位置范围，不产生实时进度、到点或访问记录。手动起点、模拟位置和设备定位明确区分。

## 5. 数据与参考照片

照片1：全景导览牌，存在反光、透视及字号限制；照片2：森林步道局部导览。可辨认的虎山服务站、虎山瀑布、碧云亭、读枫阁、揽秋湖、叠浪岩、德云亭、桃花扇亭、桃花涧等仅作待查候选。牌图不是测绘坐标，牌上的“您所在位置”不是用户设备位置。不从像素生成经纬度、不推断厕所位置。高德冲突或缺少结果列待核实，不覆盖原始证据。

厕所层初始空集，提供JSON模板、预览校验、确认导入，仅接受声明GCJ-02的用户自有数据；WGS84需先明确转换，不自动猜坐标系。未知开放/无障碍字段允许空。项目设施和高德底图自带标注分别说明。

## 6. 配置、安全和许可

### 9.3 审查发现与修复

1. 原SVG比例失真、轮询重建，未绘本次路线：真实模式改官方底图，地图实例保持，按request_id增量替换geometry，显式点击才重置视野。
2. 原模拟默认点和未知坐标可能冒充设备定位：真实模式默认unavailable，手动、device、sim分开，真实图不画旧草稿。
3. 停止定位等待聊天整轮锁：位置与停止控制在事件循环同步完成，不等模型写锁；持锁ASGI回归验证停止能返回。路线/模式写操作遇聊天占用快速409提示，不积压迟到写。
4. 对话规划撤销token后前端继续上传：409清订阅和token并提示重开；规划期间禁用开始定位、防重复开始。
5. 结构化工具结果把坐标写历史：持久化时清理tool history及tool_results，去当前高德路径和设备位置；保留用户/模型正文存档边界。
6. 新行程留旧图钉和名称：同时清变量、覆盖物、详情与文字，并保持当前模式；模拟访问明确标识。
7. 修改选择后旧SDK回调/请求迟到：前端action/generation，后端request_id/sequence双校验，取消仅作用匹配ticket，过期pending转可重试。
8. 快速模式切换及失败：串行执行，切换中禁用；失败回写真实模式，避免下拉框与地图状态不一致。
9. 只看剩余距离可能错误宣布到达：真实模式以实际距离+精度校验，模板提示不把投影末端视为确认到达；低精度/过期/跳变不产访问记录。
10. 长上下文带整条路线：真实事实去geometry和原始坐标重复，仅提供有限步骤摘要和状态；路径仍完整保存在当前地图会话供导航。

测试工具自身曾出现FastAPI路由查找方式不兼容、浏览器模拟位置更新返回不可用、异步模式切换断言过早；分别改为真实ASGI请求、显式位置夹具、等待实际DOM状态。成品首次并行检查有一次3秒资源读超时，收尾采用15秒资源预算与串行成品验证后通过；未据此宣称首次地图加载性能达标。
